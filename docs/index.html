    🔌 Endpoints da API REST

    A API Express implementa os contratos abaixo. Clique em Simular para executar a chamada no motor local e inspecionar a resposta JSON padronizada:

    GET /health Status de saúde da aplicação (RNF03)
    GET /categorias Lista todas as categorias em ordem alfabética (RF07)
    GET /transacoes Lista transações ordenadas por data decrescente (RF02, RF03)
    GET /resumo Saldo geral e totais agrupados por categoria (RF10, RF11)
    POST /transacoes (payload inválido) Demonstra validação RF12 e retorno HTTP 400 padronizado (RNF04)
    HTTP 200 OK GET /resumo
